# 핵심 작성·검수 규칙 (Paper Assistant 규칙 세트)

검수 보고서, `python -m pa check`, 역할별 검수 에이전트가 모두 이 ID를 씁니다. 규칙 문장은 이 저장소가 직접 쓴 요약이며, 널리 알려진 과학 글쓰기 원칙을 검수에 쓸 수 있게 한 줄씩 정리한 것입니다. 더 깊은 설명은 끝의 "더 읽을 자료"에 있는 책을 직접 읽으십시오. 책을 가지고 있다면 `docs/kb_building.md`의 절차로 자기만의 책 지식 베이스를 만들어 이 규칙 세트에 붙일 수 있습니다.

## 0. 우선순위

규칙이 부딪치면 위의 것이 이깁니다.

1. **대상 저널의 투고 규정과 템플릿** (`01_topic/journal.md`)
2. **하우스 규칙**: 저자·지도교수·공동 저자의 지시 (`01_topic/house_rules.md`, HR-01–)
3. **분야 프로필** (`pa/profiles/<분야>.toml`, `docs/style/profiles.md`)
4. **이 규칙 세트**와, 있다면 사용자가 만든 책 지식 베이스(`knowledge/private/`)

규칙 ID는 고정입니다. 새 규칙은 끝 번호에 붙이고, 지운 번호는 비워 둡니다.

## ST — 이야기와 논증 구조

| ID | 규칙 |
|---|---|
| ST-01 | 논문 전체가 하나의 메시지(take-home message)를 전한다. 그 메시지를 한 문장으로 쓸 수 있어야 한다. |
| ST-02 | 서론은 큰 문제(Opening) → 아직 모르는 것(Challenge) → 이 연구가 한 일(Action) → 답(Resolution)의 흐름을 따른다. 고찰과 결론은 같은 질문에 답한다. |
| ST-03 | 연구 질문이 명시적이다("~인가?" 또는 "~을 알기 위해 ~했다"). 목표만 있고 질문이 없으면 독자는 답을 알아볼 수 없다. |
| ST-04 | 공백은 구체적으로 쓴다. "거의 알려지지 않았다"가 아니라 무엇이 왜 아직 모르는지 쓴다. |
| ST-05 | 서론 첫 단락의 문제 범위와 결론의 범위가 같다(모래시계 모양: 넓게 열고, 좁혀 답하고, 다시 넓혀 의미를 말한다). |
| ST-06 | 새로움은 데이터셋이나 기법 자체가 아니라 그것으로 알게 된 것에 둔다. 새로움의 유형(아이디어·도구·방법·응용·자료·학제 결합)과 분야에 주는 진전을 한 문장으로 말할 수 있다. |
| ST-07 | 결과를 끝까지 숨기지 않는다. 초록과 서론 끝에서 답을 미리 말한다. |
| ST-08 | 단락마다 요점이 하나이고, 첫 문장(topic sentence)이 그 요점을 말한다. |
| ST-09 | 문장 끝(stress position)에 새롭고 중요한 정보를, 문장 앞(topic position)에 이미 아는 정보를 둔다. |
| ST-10 | 한 주제는 한 곳에서 다룬다. 같은 설명이 여러 절에 흩어지지 않는다. |
| ST-11 | 문제의 중요도와 결과의 쓰임(누가, 어떻게 쓰는가)이 서론과 고찰에 있다. |

## SE — 섹션 관례

| ID | 규칙 |
|---|---|
| SE-01 | 섹션 구조와 이름은 저널을 따른다. 정하지 않았으면 분야 프로필의 구조(IMRAD, 논증형 등)를 따른다. |
| SE-02 | **제목:** 구체적인 대상과 방법을 담고, 군더더기 시작("A study of", "On the")과 정의 없는 약어, 본문보다 강한 단정이 없다. 핵심 검색어를 포함한다. |
| SE-03 | **초록:** 목적·방법·결과(수치)·결론을 담는다. 배경은 4분의 1을 넘지 않는다. 본문에 없는 내용, 인용, 표 참조가 없다. 저널 형식(구조화 여부, 단어 수)을 지킨다. |
| SE-04 | **키워드:** 제목과 겹치지 않는 구체적인 검색어. 같은 분야 논문의 키워드와 대조하고 저널의 개수 상한을 지킨다. |
| SE-05 | **서론:** 상투적 첫 문장 없이 문제로 연다. 모든 단락이 문제에서 질문으로 좁혀 간다. 해법보다 문제를 먼저 쓴다. 기여는 목록으로 분명히 한다. 장황한 "이 논문의 구성" 단락은 줄이거나 지운다. |
| SE-06 | **관련 연구:** 주제별로 묶고 묶음마다 소결과 공백을 쓴다. 다른 연구는 정확하고 외교적으로 평가한다. |
| SE-07 | **방법:** 다른 연구자가 재현할 수 있을 만큼 자세하다. 자료·도구의 버전과 출처, "얼마나"에 대한 수치가 있다. 결과가 섞이지 않는다. 각 항목은 목적부터 쓴다. |
| SE-08 | **결과:** 소제목이 방법과 대응한다. 대표 자료만 싣고 크기를 먼저, 통계는 괄호에 쓴다. 부정적 결과도 보고한다. 표를 문장으로 되풀이하지 않는다. |
| SE-09 | **고찰:** 첫 단락이 연구 질문의 답이다. 선행 연구와 비교하고(일치·불일치·이유), 대안 해석을 다룬다. 결과에 없는 새 수치를 들이지 않는다. 자료 범위 밖으로 외삽하지 않는다. |
| SE-10 | **한계:** 실제 약점만, 결과에 주는 영향과 대처를 함께 쓴다. 고찰의 첫 문장과 마지막 문장에 두지 않는다. (HR-04) |
| SE-11 | **결론:** "This paper has presented"로 열지 않는다. 초록을 되풀이하지 않는다(어휘가 뚜렷이 달라야 한다). 서론의 문제에 비추어 이룬 것, 방법의 장단점, 후속 방향을 쓰되 마지막 문장을 "더 연구가 필요하다"로 끝내지 않는다. |
| SE-12 | **선언문:** 저자 기여, 이해상충, 연구비, 데이터·코드(공개 저장소와 영구 식별자), 윤리 승인·동의, 생성형 AI 사용(도구, 사용 수준, 영향 받은 부분)을 저널이 정한 위치에 쓴다. |

## EV — 근거와 수치

| ID | 규칙 |
|---|---|
| EV-01 | 원고의 모든 수치는 수치 원장(`05_data/numbers.csv`)을 거쳐 결과 파일까지 거슬러 올라갈 수 있다. 초록·본문·표·그림·보충 자료의 같은 수치가 서로 같다. (HR-05) |
| EV-02 | 반올림과 유효 숫자가 일관된다. 차이는 반올림 전에 계산한다. 작은 표본의 백분율에는 분모를 함께 쓴다. |
| EV-03 | 불확실성을 밝힌다: ±가 표준편차인지 표준오차인지 신뢰구간인지, 오차 막대의 종류, 반복 횟수. |
| EV-04 | 주장의 강도가 근거와 맞다. 측정값에는 유보어를 붙이지 않고, 해석과 일반화에만 붙인다. "모든", "항상", "증명"은 그 범위의 자료가 있을 때만 쓴다. |
| EV-05 | "유의하다(significant)"는 검정 결과와 함께만 쓴다: 검정 이름, 통계량, p, 다중 비교 보정. |
| EV-06 | 사전 등록한 조건과 지표를 모두 보고한다. 유리한 조건만 고르지 않는다. 사후에 바꾼 것은 바꿨다고 밝힌다. |
| EV-07 | 주요 결과마다 대안 해석을 하나 이상 다루고, 경쟁 가설을 자료로 배제했는지 밝힌다. |
| EV-08 | 결론이 자료보다 앞서지 않는다. 결과가 결론을 내리기에 부족하면 결론을 줄인다. |
| EV-09 | 평가에 쓰는 자료는 학습·보정·문턱 맞춤에 쓰지 않는다(자료 격리). 격리가 깨졌으면 다시 실행하거나 그 사실을 방법 절에 밝힌다. |
| EV-10 | 원고에는 확인한 수치와 관찰만 쓴다. "~때문일 것이다" 같은 추정 설명은 항목 단위로 확인한 뒤 관찰로 쓰거나 지운다. |

## DI — 표와 그림

| ID | 규칙 |
|---|---|
| DI-01 | 개수가 저널 상한 안이다. 반복 자료는 표, 추세와 관계는 그림. 같은 자료를 두 곳에 싣지 않는다. |
| DI-02 | 제목·머리글·범례만 보고도 이해된다. 의미 있는 이름을 쓰고("Model A" 금지), 약어는 각주에서 정의한다. |
| DI-03 | 번호 순으로 본문에서 언급한다. 언급하는 문장은 발견을 주어로 하고 참조는 괄호에 둔다("정확도는 12점 올랐다(그림 2)"). |
| DI-04 | 그림·표 뒤 단락의 첫 문장이 그 그림·표의 핵심 발견이다. |
| DI-05 | 축 범위와 절단을 표시하고, 오차 막대의 종류를 밝히고, 단위를 쓴다. |
| DI-06 | 색만으로 구분하지 않는다. 선 모양·표식도 달리하고, 색맹 안전 팔레트를 쓴다. |
| DI-07 | 데이터 선은 가늘고 표식은 작게 해 겹친 계열이 뭉개지지 않게 한다. 자료를 잘라 내지 않는다. 밀집 구역은 확대 삽입도로 보인다. |
| DI-08 | 게재 크기에서 글자가 읽힌다(대개 6–8 pt 이상). 래스터는 저널 해상도(흔히 300–600 dpi) 이상이고 벡터 사본이 있다. |
| DI-09 | 여러 표·그림의 순서·형식·기호·글꼴이 같다. 표는 가로선 위주(세 줄 표), 템플릿이 다르면 템플릿을 따른다. |
| DI-10 | 표와 그림은 스크립트로 만든다. 손으로 고친 값이 없고, 스크립트는 수치 원장과 같은 결과 파일을 읽는다. |

## LA — 문장과 어휘 (영어 원고, 한국어 원고에도 대부분 적용)

| ID | 규칙 |
|---|---|
| LA-01 | 문장 길이: 분야 프로필의 목표 평균을 따른다(공학 15–18단어). 검토선을 넘는 문장은 모두 보고, 상한을 넘는 문장은 나눈다. 남기는 긴 문장은 짧은 주절이 핵심을 먼저 말한다. |
| LA-02 | 주어를 앞에 두고 주어와 동사 사이를 짧게(8–10단어 이내) 한다. |
| LA-03 | 아는 정보에서 새 정보로 간다. 부정과 제한은 문장 앞쪽에 둔다. |
| LA-04 | 명사화를 동사로 되돌린다("perform an analysis" → "analyse"). |
| LA-05 | 장황한 표현을 줄인다("in order to" → "to", "due to the fact that" → "because", "utilize" → "use"). |
| LA-06 | 메타담화와 빈 서두를 지운다("It is important to note that", "It was found that", "clearly"). |
| LA-07 | 빈 증폭어(very, extremely, 매우)를 지우거나 수치로 바꾼다. |
| LA-08 | 강조어(remarkably, notably)는 원고 전체에서 두 번 이하. |
| LA-09 | 자기 결과에 과장어를 쓰지 않는다(novel, crucial, pivotal, state-of-the-art). 구체적인 성질과 비교 수치로 쓴다. |
| LA-10 | 한 대상은 끝까지 같은 용어로 부른다. 분야의 표준 용어를 쓴다. |
| LA-11 | 약어는 첫 사용에서 정의하고, 정의한 뒤에는 약어만 쓴다. 두 번 이하로 쓰는 약어는 풀어 쓴다. |
| LA-12 | 모호성을 없앤다: which/that 구분, 매달린 분사구(dangling modifier), 지시 대상이 둘 이상인 this/it, respectively의 짝. |
| LA-13 | 시제: 확립된 지식은 현재형(인용과 함께), 이 연구의 방법과 관찰은 과거형, 그림·표가 보여 주는 것은 현재형. 자기 연구에 현재완료를 남용하지 않는다. (HR-02) |
| LA-14 | 철자를 하나로 통일한다(US 또는 UK, 저널 규정). |
| LA-15 | 실재 단어 오타를 찾는다(form/from, trial/trail, then/than, casual/causal). 맞춤법 검사기가 놓친다. |
| LA-16 | 1인칭은 저널 규정 → 하우스 규칙 → 분야 프로필 순으로 정한다. 금지라면 수동태, 무생물 주어("This study shows"), 주어 생략으로 바꾼다. |
| LA-17 | "significant"·"유의"는 통계적 의미로만 쓴다(EV-05). 일상적 뜻이면 "large", "substantial", "큰"으로 바꾼다. |
| LA-18 | 상투적 첫 문장을 쓰지 않는다("In recent years", "has attracted increasing attention", "최근 들어"). |
| LA-19 | 상투적 결론 표현을 쓰지 않는다("may provide new insights", "more research is needed", "새로운 통찰"). 통찰의 내용과 다음 연구를 구체적으로 쓴다. |
| LA-20 | 다른 연구를 비판할 때 어조를 확인한다("failed to", "ignored" 대신 "did not address"). |
| LA-21 | "e.g."와 "etc."를 함께 쓰지 않는다. |
| LA-22 | 유보어는 겹치지 않는다("may possibly"). 측정값에는 붙이지 않는다(EV-04). |
| LA-23 | 도치·은유·관용구 없이 평이하게 쓴다. 목적어나 목적을 빠뜨려 지나치게 압축하지 않는다. (HR-02) |
| LA-24 | "As can be seen in Figure 2"처럼 그림을 주어로 하지 않고, 발견을 주어로 하고 참조를 괄호에 둔다(DI-03). |
| LA-25 | 단락은 분야 프로필의 상한 안에서 끊는다(공학 약 150단어). |

## KO — 한국어 문장 (분야 프로필 `korean`)

| ID | 규칙 |
|---|---|
| KO-01 | 번역투 "~에 있어(서)"를 "~에서", "~할 때"로 쓴다. |
| KO-02 | "~을 통해(서)"를 남용하지 않는다. "~으로", "~해서"로 바꿀 수 있으면 바꾼다. |
| KO-03 | 이중 피동("되어지다", "~지게 되다")을 쓰지 않는다. |
| KO-04 | 결과 서술에 추정 어미("~것으로 보인다", "~것으로 판단된다")를 쓰지 않는다. 측정값은 단정하고, 해석만 근거와 함께 유보한다. |
| KO-05 | "~을 가진다/갖는다"의 직역("의미를 가진다")을 "~이 있다", "~하다"로 쓴다. |
| KO-06 | "~에 대한"을 한 문장에서 겹쳐 쓰지 않는다. |
| KO-07 | 복수 "~들"을 필요한 곳에만 쓴다. |
| KO-08 | 문장 길이는 공백을 뺀 글자 수로 보고, 분야 프로필의 검토선(80자)·상한(120자)을 지킨다. |
| KO-09 | 문체를 하나로 통일한다(학술지 본문은 대개 한다체, 보고서·답변서는 합니다체). |
| KO-10 | "~하는 것이 필요하다"를 "~해야 한다"로 쓴다. |
| KO-11 | "~(으)로부터"를 "~에서"로 바꿀 수 있으면 바꾼다. |
| KO-12 | "~에 의해" 피동 대신 행위 주체를 주어로 쓸 수 있으면 능동으로 쓴다. |
| KO-13 | 외래어·전문 용어는 처음 나올 때 원어를 괄호에 병기하고, 학회 표준 용어집을 따른다. |
| KO-14 | 영문 초록은 국문 초록의 번역이 아니라 같은 내용을 영어 규칙(LA)으로 다시 쓴 것이다. |

## RE — 참고문헌과 연구 윤리

| ID | 규칙 |
|---|---|
| RE-01 | 본문 인용과 참고문헌 목록이 1:1로 맞는다. |
| RE-02 | 모든 항목의 저자, 연도, 제목, 게재처, 권, 쪽, DOI를 원문 기록(Crossref, arXiv, 출판사, 학회 기록)과 대조한다. 게재본이 있는 프리프린트는 게재본으로 인용한다. (HR-06) |
| RE-03 | 인용한 사실이 원문에 있고, 그 문헌의 결론을 정확히 대변한다. 문헌 카드의 판정이 Supported 또는 Usage citation이어야 한다. |
| RE-04 | 형식이 저널 규정과 같다(APA 7의 et al. 규칙, 번호식의 순서 등). |
| RE-05 | 남의 문장은 인용부호와 출처를 단다. 출처 없는 바꿔 쓰기를 하지 않는다. 자기 이전 논문의 문장도 재사용하지 않는다. 유사도 검사를 한다. |
| RE-06 | 자료의 정체를 확인한다. 원고에서 부르는 데이터셋·도구 이름이 실제로 불러온 자료와 같다. |
| RE-07 | 사람·동물을 다루면 윤리 승인, 동의, 등록 번호를 밝힌다. 저자 자격, 이해상충, 이중 투고, 그림 재사용 허가를 확인한다. |
| RE-08 | 연구를 직접 뒷받침하는 문헌만 싣고, 자기 인용이 과하지 않다. |
| RE-09 | 생성형 AI 사용을 저널 규정의 위치에 도구·사용 수준·영향 받은 부분과 함께 공개한다. AI는 저자가 아니며, 내용의 책임은 저자에게 있다. |
| RE-10 | 원문 파일은 열린 사본(OA)이나 정당한 경로로만 얻는다. 저작물을 공개 저장소에 올리지 않는다. |

| ED-01 | 범위: 저널의 Aims & Scope에 맞는가? 서론 첫 단락만 읽어도 그 분야 문제로 보이는가? | 차단 |

| ED-05 | 준수: 분량·형식·선언문·윤리 규정을 모두 지켰는가? | 차단 |
| ED-06 | 진전: 분야에 무엇을 더하는지 한 문장으로 말할 수 있는가? | 수정 |

## PK — 최종 점검과 투고 묶음

| ID | 규칙 |
|---|---|
| PK-01 | 분량·초록·표·그림 수가 저널 상한 안이다. |
| PK-02 | Figure/Fig., 캡션, 번호, 약어, 단위 표기가 원고 전체에서 같다. |
| PK-03 | 자리 표시([TODO], [TBD], [ref], `\tbd{}`)가 0개다. |
| PK-04 | 그림 파일이 저널의 형식·해상도·폭을 지킨다(`pa fig check`). |
| PK-05 | LaTeX 원본은 빈 폴더에 풀어 다시 조판해도 오류·미해결 참조 없이 만들어진다(`pa build package`). |
| PK-06 | 맹검 원고에서 저자명, 소속, 자기 저장소 주소, 사사, 파일 속성이 빠졌고, 자기 인용은 3인칭이다. |
| PK-07 | 제목 페이지, 선언문, 커버 레터(기여, 저널 적합성, 미중복 투고 진술)가 있다. |
| PK-08 | 저널 체크리스트의 항목별 확인, 필요한 파일 전부, 교신 저자 정보와 ORCID. |
| PK-09 | 데이터·코드 공개 위치와 영구 식별자(DOI)가 실제로 열린다. |
| PK-10 | 공저자 원고를 합친 뒤 시제·용어·대명사가 일관된다. 마지막으로 소리 내어 한 번 읽는다. |

## RV — 수정본과 답변서

| ID | 규칙 |
|---|---|
| RV-01 | 모든 의견에 번호별로 답한다. 말없이 건너뛴 의견이 없다. |
| RV-02 | 원고를 고친 답에는 정확한 위치(절, 쪽, 표·그림)를 적는다. |
| RV-03 | 동의하지 않는 의견에는 정중하고 구체적인 근거를 댄다. 오해에서 나온 의견도 원고 문장을 고쳐 다음 독자의 오해를 막는다. |
| RV-04 | 방어 문구, 감정 표현, 같은 말의 반복을 쓰지 않는다. 완전한 문장으로 쓴다. |
| RV-05 | 변경 표시는 저널이 정한 방식(변경 추적, 색)을 따르고, 표시본과 깨끗한 본이 같은 내용이다. |
| RV-06 | 수정 때문에 다른 곳(초록, 결론, 표)의 수치가 어긋나지 않는다(EV-01). |
| RV-07 | 요청 밖에서 고친 것도 답변서에 따로 적고, 논문에 반영했는지 구분한다. |
| RV-08 | 재실험으로 후퇴한 주장은 원고에서 이력 없이 고치고, 경위는 답변서에만 쓴다(HR-03). |

## 더 읽을 자료

이 규칙 세트는 아래 책과 편집자 지침에서 널리 가르치는 원칙을 이 저장소의 말로 요약한 것입니다. 원문을 옮기지 않았습니다.

- Joshua Schimel, *Writing Science: How to Write Papers That Get Cited and Proposals That Get Funded* (Oxford University Press) — 이야기 구조, 단락, 문장의 topic·stress 위치.
- Barbara Gastel & Robert A. Day, *How to Write and Publish a Scientific Paper* (Greenwood/Cambridge) — 섹션 관례, 표·그림, 참고문헌, 윤리, 투고와 심사.
- Adrian Wallwork, *English for Writing Research Papers* (Springer) — 영어 문장, 어휘, 시제, 섹션별 표현, 최종 점검.
- 출판사·학회의 저자 안내와 편집자 웨비나(예: IEEE Author Center, Elsevier Researcher Academy, Springer Nature 저자 안내) — 편집자의 판정 기준과 반려 사유, 답변서.
- 보고 지침: EQUATOR Network(CONSORT, STROBE, PRISMA 등), APA Publication Manual, Chicago Manual of Style.
