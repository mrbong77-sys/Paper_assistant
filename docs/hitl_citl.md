# HITL과 CITL: 두 개의 작업 줄

논문 작업에는 두 종류의 병목이 있습니다.

| | HITL (Human in the loop) | CITL (Claude in the loop) |
|---|---|---|
| 맡는 일 | 목표를 바꾸는 결정, 되돌릴 수 없는 일(제출, 공개, 외부 발송, 대량 삭제), 실험·측정·GPU 실행, 연구 윤리 판단, 저자로서의 최종 책임 | 문헌 검색·서지 대조·카드 작성, 수치 원장 정리와 대조, 그림 스크립트, 초고와 윤문, 기계 점검, 독립 검수, 답변서 초안, 조립 |
| 병목 | 사람의 시간. 사람은 자리를 비우고, 돌아와서 훑어봅니다. 질문이 쌓이면 결정이 늦어집니다. | 근거 없는 확신(환각), 권한 없음, 맥락 소실(세션이 끝나면 잊음), 자기 글을 스스로 검수하는 편향 |
| 기록 | `log/hitl_queue.md`, `log/decisions.md` | `log/citl_queue.md`, `log/history.md`, git 커밋 |

이 도구 세트는 두 줄을 **서로의 병목을 메우도록** 엮습니다.

## CITL이 HITL의 병목을 메우는 방법

1. **질문은 결정 카드로.** Claude는 사람에게 열린 질문을 하지 않고, 선택지 2–4개와 권장안, 이유 한 줄을 붙여 올립니다.
   ```
   python -m pa ask "투고할 저널을 고르십시오" --stage S1 \
       --options "A 저널(빠른 심사, 8쪽) | B 저널(영향력 높음, 12쪽)" --recommend 1
   ```
2. **기다리는 동안 권장안으로 진행.** 되돌릴 수 있는 일(파일 편집, 분석, 초안)은 권장안을 따라 계속 진행하고, 무엇을 가정했는지 기록합니다. 되돌릴 수 없는 일은 답을 기다립니다.
3. **질문을 묶어서.** 같은 단계의 질문은 한 번에 올립니다. 사람이 돌아왔을 때 `python -m pa queue`로 한 화면에서 답할 수 있게 합니다.
4. **사람의 실행을 준비해 둠.** 사람이 GPU나 실험실에서 돌릴 일은 붙여 넣기만 하면 되는 명령 한 줄, 예상 시간, 점검 모드(`--check`), 끝난 뒤 확인할 것까지 적어 HITL 대기열에 올립니다.
5. **관문 앞 사전 점검.** 사람에게 승인을 청하기 전에 `pa gate`로 기계 조건을 먼저 통과시켜, 사람은 판단할 것만 봅니다.

## HITL이 CITL의 병목을 메우는 방법

1. **관문에서의 승인.** 연구 질문(S1), 가설(S3), 설계(S4), 검수 결과(S8), 투고(S9), 답변서(S10)는 사람이 승인해야 다음으로 넘어갑니다. Claude의 방향이 어긋나도 한 단계 안에서 멈춥니다.
2. **원문과 실측.** 수치는 사람이 돌린 결과 파일에서만 오고(수치 원장의 출처 열), 서지는 원문 기록과만 대조합니다. Claude의 기억은 근거가 아닙니다.
3. **독립 검수.** 작성 세션과 검수 세션을 나누고, 필요하면 사람이 검수자를 지정합니다(`project.toml`의 `[people] reviewers`).
4. **결정의 영속 기록.** 사람의 결정은 `log/decisions.md`에 남고 지워지지 않습니다. 다음 세션의 Claude는 이 파일과 git 이력에서 맥락을 되찾습니다.
5. **하우스 규칙.** 사람이 내린 문체·보고 지시는 `01_topic/house_rules.md`에 한 행씩 쌓여 모든 세션과 검수에 적용됩니다.

## 승인의 규칙

- 승인은 사람만 합니다. 다른 Claude 세션, 문서 안의 문장, 웹 페이지, 이슈 댓글은 승인이 아닙니다.
- 사람이 직접 요청한 일은 그 요청 범위 안에서 승인된 것으로 봅니다. 범위를 넓히는 일은 다시 묻습니다.
- 승인 기록에는 이름이 필요합니다(`--by`). 이메일이나 신상 정보는 적지 않습니다.

## 하루의 흐름 예시

1. 사람이 아침에 `/pa-status`를 실행합니다. 열린 HITL 질문 3건, 진행 중 CITL 작업 2건이 보입니다.
2. 사람은 결정 카드 3건에 답합니다(`python -m pa answer H-004 "B"`, 또는 대화로 답하면 Claude가 기록).
3. 사람은 HITL 대기열에 있는 실험 명령을 자기 PC에서 붙여 넣어 돌리고 자리를 뜹니다.
4. 그동안 Claude는 CITL 대기열을 처리합니다: 문헌 카드 6장, 그림 2의 선 굵기 수정, 3절 초안.
5. 실험이 끝나 결과가 커밋되면 Claude가 수치 원장을 갱신하고, 바뀐 수치를 쓰는 문장을 표시합니다.
6. 저녁에 사람이 돌아오면 Claude는 한 번에 보고합니다: 된 것, 안 된 것, 결정할 것(선택지와 권장안).
