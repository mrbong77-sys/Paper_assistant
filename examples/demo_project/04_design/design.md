# 실험 설계와 사전 등록 (S4)

## 1. 설계 개요
- 연구 질문과 가설: `03_hypotheses/hypotheses.md`의 H1, H2
- 설계 유형: 합성 자료에서의 통제 비교 실험
- 분석 단위와 표본: (거리 d, seed) 칸 25개. 칸마다 학습 200점, 시험 1,000점(클래스 균형).

## 2. 조건과 변인
| 구분 | 내용 |
|---|---|
| 독립 변인(조건) | 분류기(로지스틱 회귀, 최근접 중심), 클래스 간 거리 d ∈ {0.5, 1.0, 1.5, 2.0, 3.0} |
| 종속 변인(측정값) | 시험 정확도 |
| 통제 변인(고정값) | 2차원, 등분산 등방 가우스(표준편차 1), seed 0–4, 로지스틱 회귀 300회 배치 경사 하강(학습률 0.5) |
| 기준선·비교 대상 | 최근접 중심 분류기, 베이즈 최적 정확도 Φ(d/2) |
| ablation(구성 요소별 기여) | 해당 없음(두 모형 비교) |

## 3. 지표와 운영점
- 주 지표: 시험 정확도(클래스 균형이므로 정확도가 오분류율과 같은 정보를 줌)
- 보조 지표: 베이즈 최적과의 차이
- 운영점·문턱: 로지스틱 회귀의 결정 문턱 0.5(학습 자료로 맞추지 않음)

## 4. 자료 격리
- 학습에 쓰는 자료: 칸마다 학습 200점
- 평가에만 쓰는 자료: 칸마다 시험 1,000점(같은 생성기, 학습 뒤에 뽑음)
- 강제 방법: 스크립트가 학습 함수에 학습 자료만 넘김(`run_benchmark.py`)

## 5. 분석 계획
- 통계 검정: 칸별 차이(로지스틱 − 최근접 중심)의 정확 양측 부호 검정, 동점 제외. 검정 하나라 다중 비교 보정 없음.
- 신뢰구간·효과 크기: 거리별 평균과 seed 간 표준편차, 평균 차이(점).
- 결측·제외 기준: 없음.
- 판정: H1은 평균 차이 > 0이고 부호 검정 p < 0.05에서 로지스틱이 우세할 때 지지. H2는 최대 차이 < 2점일 때 지지.

## 6. 재현성
- 고정한 seed, 버전: seed 0–4, Python 3.11 이상, 표준 라이브러리만
- 실행 명령: `python examples/demo_project/05_data/scripts/run_benchmark.py` → `make_ledger.py`
- 실행 방식: 명령 한 줄, 끝난 칸은 건너뜀(이어서 실행), `--check` 소규모 점검 모드
- 결과 파일: `05_data/processed/results.json`
