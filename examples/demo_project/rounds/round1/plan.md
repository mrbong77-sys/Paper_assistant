# Round 1: 수정 계획

의견마다 한 행입니다. 맡는 쪽을 HITL(사람: 실험 재실행, 판단, 승인)과 CITL(Claude: 문장 수정, 수치 대조, 문헌 확인)로 나눕니다.
사람의 판단이 필요한 항목은 HITL 대기열에 선택지와 권장안을 붙여 올리고, 그동안 CITL 항목을 진행합니다.

|---|---|---|---|---|---|---|

## 원칙
- 꼭 필요한 조치만 합니다. 방어 문구와 같은 말의 반복은 쓰지 않습니다.
- 재실험으로 후퇴한 주장은 원고에서 이력 없이 고치고, 설명은 답변서에만 둡니다(HR-03).
- 원고에는 측정값과 조건만 씁니다. 우위의 논거는 답변서에 씁니다.
- 요청 밖에서 고친 것은 `responses.toml`의 `[[own]]`에 적고, 논문 반영 여부(`in_paper`)를 구분합니다.
