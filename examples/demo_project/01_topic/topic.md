# 주제 구체화 (S1)

> 이 예시 프로젝트는 도구 사용법을 보이기 위한 가상의 연구입니다. 자료는 스크립트가 만든 합성 자료이고, 저널은 실재하지 않습니다.

## 확정 내용 (관문 S1에서 사람이 승인)

| 항목 | 한 문장 |
|---|---|
| 큰 문제 (O: Opening) | 작은 표본으로 이진 분류기를 고를 때, 실무자는 흔히 더 유연한 모형(로지스틱 회귀)이 단순한 모형보다 낫다고 가정한다. |
| 공백 (C: Challenge) | 두 클래스가 등분산 가우스 분포이고 겹침이 클 때, 로지스틱 회귀가 최근접 중심 분류기보다 시험 정확도에서 실제로 앞서는지, 앞선다면 얼마나 앞서는지가 같은 조건에서 비교되지 않았다. |
| 연구 질문 (RQ) | RQ1: 클래스 간 거리 d가 0.5–3 표준편차일 때, 로지스틱 회귀의 시험 정확도는 최근접 중심 분류기보다 높은가? RQ2: 두 분류기는 베이즈 최적 정확도에서 얼마나 떨어져 있는가? |
| 접근 (A: Action) | 다섯 거리 × 다섯 고정 seed의 합성 자료(학습 200점, 시험 1,000점)로 두 분류기를 학습·평가하고, 칸별 차이를 부호 검정으로 비교한다. |
| 기대 답의 형태 (R: Resolution) | 거리별 평균 정확도와 그 차이, 부호 검정 결과, 베이즈 최적과의 최대 차이. |
| 기여의 유형 | 방법 비교(재현 가능한 통제 실험). 단순한 기준선이 이 조건에서 충분한지 실무자가 판단할 근거를 준다. |
| 쓰임 | 작은 표본의 분류 문제에서 기준선 모형을 고르는 실무자와, 새 분류기를 평가할 때 기준선을 정하는 연구자. |
| 범위 밖 | 비등분산·비가우스 분포, 고차원, 정규화와 하이퍼파라미터 탐색. |
| 대상 독자와 저널 후보 | 응용 기계 학습 실무자. Journal of Example Studies (가상). |
