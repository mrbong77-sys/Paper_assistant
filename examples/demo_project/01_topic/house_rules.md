# 하우스 규칙 (우선순위 2: 저널 규정 다음, 문체 규칙 위)

저자·지도교수·공동 저자가 정한 규칙입니다. 새 지시는 한 행으로 더하고, 출처(누가, 언제)를 적습니다.
기본값 HR-01–HR-08은 Paper Assistant의 권장안이며, 이 프로젝트에 맞지 않으면 지우지 말고 "적용 안 함"으로 표시합니다.

| ID | 규칙 | 적용 | 출처 |
|---|---|---|---|
| HR-01 | 1인칭 사용 여부는 저널과 저자가 정한다. 정하지 않았으면 분야 프로필을 따른다. | 적용 | 기본값 |
| HR-02 | 도치·은유·관용구 없이 명시적으로 쓴다. 일반 사실은 현재형과 인용으로, 이 연구의 관찰은 과거형과 범위("이 평가에서")로 쓴다. | 적용 | 기본값 |
| HR-03 | 논문에는 경과가 아니라 결과를 쓴다. 개발 중 버전, 재실험·재채점 경과는 내부 기록(log, 답변서)에만 둔다. 연구 질문에 필요한 비교는 ablation으로만 쓴다. | 적용 | 기본값 |
| HR-04 | 한계 절에는 실제 약점만, 영향과 대처를 함께 쓴다. 범위와 정의는 방법 절에 한 번만 쓴다. | 적용 | 기본값 |
| HR-05 | 원고의 모든 수치는 수치 원장(`05_data/numbers.csv`)의 출처 파일까지 거슬러 올라갈 수 있어야 한다. 원고에는 확인한 수치와 관찰만 쓰고, 추론은 채팅·내부 기록에서만 추론이라고 밝혀 쓴다. | 적용 | 기본값 |
| HR-06 | 참고문헌은 원문(출판사, DOI 기록, arXiv, 학회 기록)에서 서지를 확인한 것만 쓴다. 인용한 사실은 원문에서 쪽까지 확인한다. | 적용 | 기본값 |
| HR-07 | 저장소 설정, 내부 코드명, 실험 번호를 원고 라벨로 쓰지 않는다. 원고에서 정한 이름만 쓴다. | 적용 | 기본값 |
| HR-08 | 설계 오류를 찾으면 "한계"로 적지 않고 다시 실행해 바로잡는다. 다시 할 수 없을 때만 한계로 쓴다. | 적용 | 기본값 |
