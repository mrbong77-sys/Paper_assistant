S2 자료 수집과 문헌 지식 베이스. 인자: $ARGUMENTS. 절차의 상세는 `docs/kb_building.md` 1절입니다.

1. **검색 계획.** `01_topic/topic.md`의 RQ에서 검색어 묶음을 만들고 사람에게 확인합니다(빠진 하위 주제, 기간, 언어). 체계적 문헌 고찰이면 포함·제외 기준을 먼저 정합니다.
2. **검색.** 쓸 수 있는 도구(alphaXiv, 웹 검색, 학회·출판사 검색)로 찾고, 검색마다 `02_literature/search_log.md`에 날짜·DB·검색어·필터·결과 수·고른 수를 적습니다.
3. **추가.** 고른 문헌마다 원 기록으로 추가합니다. 기억으로 서지를 쓰지 않습니다.
   ```
   python -m pa refs add --doi <DOI>        # 또는 --arxiv <번호>, --title "<정확한 제목>"
   ```
4. **대조.** `python -m pa refs verify`. 차이가 나오면 원 기록에 맞게 고치고, 게재본이 있는 프리프린트는 게재본으로 바꿉니다. DOI·arXiv가 없는 책·보고서는 사람이 확인한 출처를 받아 `python -m pa refs manual --key <키> --note "<확인한 곳>"`.
5. **원문.** `python -m pa refs fetch`(환경 변수 `PA_EMAIL`이 있으면 Unpaywall 사용). "no open copy" 목록은 사람에게 HITL로 넘깁니다(도서관·저자 요청). 페이월을 우회하지 않습니다.
6. **텍스트.** `python -m pa refs text`.
7. **카드.** 원고 초고가 있으면 먼저 `python -m pa refs contexts`. 그다음 `python -m pa refs cards`로 뼈대를 만들고, 원문을 읽어 카드마다 채웁니다:
   - 기록 대조 결과, 무엇을 한 연구인가(자기 말로, 수치와 쪽), 원고에 쓸 수 있는 사실(쪽), 인용 문장별 판정과 근거(짧은 인용, 쪽), 고칠 방향.
   - 원문에서 확인하지 못한 사실은 쓰지 않습니다.
   - 카드가 많으면 문헌별로 나눠 병렬로 채워도 됩니다(각 작업은 카드 한 장만 씀).
8. **종합.** `02_literature/synthesis.md`에 주제별 묶음, 묶음별 소결, 공백, RQ와의 관계를 씁니다. 이것이 관련 연구 절의 재료입니다.
9. **관문.** `python -m pa gate S2` → 기계 조건이 통과되면 사람에게 문헌 목록과 공백 요약을 보여 승인을 청합니다. 커밋합니다(원문 PDF·텍스트는 커밋되지 않음).
