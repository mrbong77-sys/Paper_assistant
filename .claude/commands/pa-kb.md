argument-hint: <책 파일 경로> [접두어]

책 지식 베이스 만들기. 인자: $ARGUMENTS. 절차는 `docs/kb_building.md` 2절입니다.

1. 사람이 그 책을 정당하게 가지고 있는지, 결과를 어디에 둘지(`knowledge/private/`, git 제외) 확인합니다. 공개 저장소에는 두지 않습니다.
2. 책의 서지(제목, 판, 출판사, 연도)와 맡을 층, ID 접두어를 정합니다.
3. 텍스트가 없으면 뽑습니다(`pdftotext -layout`). 추출 텍스트도 `knowledge/private/` 아래에만 둡니다.
4. 장마다 규칙을 뽑습니다: ID, 규칙(자기 말로 한 줄), 이유, 점검 방법, 원전 위치(장·절·쪽). 원문을 길게 옮기지 않습니다. 장이 많으면 장별로 나눠 병렬로 처리합니다.
5. 정규식으로 잡을 수 있는 규칙은 후보 목록을 따로 만들고, 사람이 원하면 분야 프로필의 `extra_phrases`에 넣습니다.
6. `docs/style/core_rules.md`와 대응표(같음 / 더 엄격 / 다름)를 만들고, 다른 규칙은 어느 쪽을 따를지 사람에게 묻습니다(HITL). 답은 하우스 규칙에 적습니다.
7. `knowledge/private/index.md`에 등록합니다. 이후 `/pa-review`와 `/pa-polish`가 이 ID를 함께 인용합니다.
