# 수치 감사 (검수 3단계)

1. `python -m pa numbers audit`를 돌려 미추적 수치 목록을 얻습니다. 맡은 범위(호출 때 받은 섹션, 없으면 전체)의 **모든** 수치를 확인합니다: 개수, 백분율, 평균, 범위("12–30%"), p 값, 통계량, 문턱, 크기, 시간, 비율("3배"), "다섯 중 넷" 같은 셈. 참고문헌 연도·쪽, 절·표 번호는 건너뜁니다.
2. 각 수치를 `05_data/numbers.csv`의 행과 그 `source` 결과 파일에서 직접 다시 읽어 대조합니다. 파생값(평균, 차이, 비율, 반올림)은 직접 다시 계산합니다. 차이는 반올림 전에 계산합니다.
3. 원고 안에서 같은 수치가 다르게 쓰인 곳(초록 vs 본문 vs 표)도 찾습니다(EV-01).
4. 판정: OK / ROUNDING(방어 가능한 반올림 차이) / MISMATCH(출처가 다름) / UNTRACEABLE(실제로 찾아도 출처 없음, 찾은 곳을 적음) / WORDING(수치는 맞지만 문장이 자료가 보이지 않는 것을 주장).
5. 함께 봅니다: 분모(EV-02), 불확실성 표기(EV-03), 검정과 "유의"(EV-05), 사전 등록 조건이 모두 보고됐는지(EV-06, `04_design/design.md`와 대조).
6. 보고서: 요약 줄(확인한 수치 N개, 판정별 개수), OK가 아닌 항목 표(위치와 짧은 인용, 원고 값, 출처 파일과 키 또는 계산, 출처 값, 고친 문장), 감사할 수 있게 OK 항목의 짧은 목록(위치: 값 ← 출처). MISMATCH와 UNTRACEABLE은 차단입니다.

## 공통 규칙
- 읽기 전용입니다. 원고, 데이터, 설정을 고치지 않고, 커밋·푸시하지 않습니다. 쓰는 파일은 맡은 보고서 하나뿐입니다.
- 네트워크가 필요한 명령(`pa refs verify`)은 맡은 역할일 때만 돌립니다. GPU·모델 다운로드는 하지 않습니다.
- 기준의 우선순위: 저널 규정(`01_topic/journal.md`) > 하우스 규칙(`01_topic/house_rules.md`) > 분야 프로필(`pa/profiles/<field>.toml`) > `docs/style/core_rules.md` > `knowledge/private/`(있으면).
- 발견마다 한 행: 단계, 등급(차단/수정/권고), 위치(섹션·줄), 규칙 ID, 문제, 고칠 방향(가능하면 고친 문장). 등급 기준은 `docs/review_procedure.md`.
- 원고가 이미 맞는 곳은 다시 쓰지 않습니다. 꼭 필요하거나 정확성·명료성이 분명히 나아지는 항목만 올립니다.
- 보고서 첫머리에 대상(파일, 커밋), 기준, 요약 표, 그리고 "차단 N건, 수정 N건, 권고 N건입니다." 줄을 씁니다.
- 마지막 메시지에는 요약 줄과 차단·수정 항목만 씁니다.
