# 언어 편집 (검수 5단계)

1. `python -m pa check <원고> --out <보고서 폴더>/check.md`를 돌립니다. 후보를 하나씩 판정합니다(고침/남김과 이유). 기계 점검이 문장을 잘못 끊은 곳(머리글자, 인용 괄호)은 실제 길이를 다시 셉니다.
2. 1인칭(LA-16): 금지된 프로젝트에서는 0이어야 합니다(차단).
3. 문장 길이(LA-01): 프로필의 상한을 넘는 문장은 나눈 문장을 제안합니다. 목록·인용 괄호 때문에 길어진 것은 따로 표시합니다. 제안을 다 반영했을 때의 건수도 셉니다.
4. 어순과 정보 흐름(LA-02, LA-03, ST-09), 간결성(LA-04–LA-08), 모호성(LA-12), 용어 일관성(LA-10, LA-11, HR-07), 시제(LA-13), 평이한 문체(LA-23: 도치, 은유, 관용구), 철자 통일(LA-14), 실재 단어 오타(LA-15).
5. 한국어 원고는 KO-01–KO-14와 문체 통일(KO-09)을 봅니다.
6. 분야 문체는 `docs/style/polishing.md`의 분야별 점검표를 따릅니다.
7. 보고서 첫머리에 수치 요약: 문장 수, 평균 길이, 검토선·상한 초과 수, 1인칭 수, 도치·은유 후보 수.

## 공통 규칙
- 읽기 전용입니다. 원고, 데이터, 설정을 고치지 않고, 커밋·푸시하지 않습니다. 쓰는 파일은 맡은 보고서 하나뿐입니다.
- 네트워크가 필요한 명령(`pa refs verify`)은 맡은 역할일 때만 돌립니다. GPU·모델 다운로드는 하지 않습니다.
- 기준의 우선순위: 저널 규정(`01_topic/journal.md`) > 하우스 규칙(`01_topic/house_rules.md`) > 분야 프로필(`pa/profiles/<field>.toml`) > `docs/style/core_rules.md` > `knowledge/private/`(있으면).
- 발견마다 한 행: 단계, 등급(차단/수정/권고), 위치(섹션·줄), 규칙 ID, 문제, 고칠 방향(가능하면 고친 문장). 등급 기준은 `docs/review_procedure.md`.
- 원고가 이미 맞는 곳은 다시 쓰지 않습니다. 꼭 필요하거나 정확성·명료성이 분명히 나아지는 항목만 올립니다.
- 보고서 첫머리에 대상(파일, 커밋), 기준, 요약 표, 그리고 "차단 N건, 수정 N건, 권고 N건입니다." 줄을 씁니다.
- 마지막 메시지에는 요약 줄과 차단·수정 항목만 씁니다.
