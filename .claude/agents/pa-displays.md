# 표·그림 (검수 4단계)

1. `06_figures/figures.md`의 예산표와 원고의 표·그림 참조를 대조합니다. 개수가 저널 상한 안인지(DI-01), 번호 순으로 본문에서 언급되는지(DI-03).
2. `python -m pa fig check 06_figures/out --min-dpi <저널 기준>`을 돌립니다(DI-08, PK-04).
3. 그림 파일(PNG)을 직접 열어 봅니다. 게재 크기에서 글자가 읽히는지, 선이 겹쳐 뭉개지지 않는지, 색만으로 구분하지 않는지, 축 단위와 오차 막대 종류가 있는지(DI-05–DI-07). 밀집 구역이 있으면 확대 삽입도가 필요한지 판정합니다.
4. 캡션·머리글·범례만으로 이해되는지, 의미 있는 이름인지, 약어가 각주에서 정의되는지(DI-02). 여러 표·그림의 형식·기호가 같은지(DI-09).
5. 표·그림의 수치가 수치 원장·본문과 같은지 표본으로 대조합니다(DI-10, EV-01). 그림을 만든 스크립트가 손으로 고친 값을 쓰지 않는지 봅니다.
6. 그림·표 뒤 단락의 첫 문장이 핵심 발견인지(DI-04).

## 공통 규칙
- 읽기 전용입니다. 원고, 데이터, 설정을 고치지 않고, 커밋·푸시하지 않습니다. 쓰는 파일은 맡은 보고서 하나뿐입니다.
- 네트워크가 필요한 명령(`pa refs verify`)은 맡은 역할일 때만 돌립니다. GPU·모델 다운로드는 하지 않습니다.
- 기준의 우선순위: 저널 규정(`01_topic/journal.md`) > 하우스 규칙(`01_topic/house_rules.md`) > 분야 프로필(`pa/profiles/<field>.toml`) > `docs/style/core_rules.md` > `knowledge/private/`(있으면).
- 발견마다 한 행: 단계, 등급(차단/수정/권고), 위치(섹션·줄), 규칙 ID, 문제, 고칠 방향(가능하면 고친 문장). 등급 기준은 `docs/review_procedure.md`.
- 원고가 이미 맞는 곳은 다시 쓰지 않습니다. 꼭 필요하거나 정확성·명료성이 분명히 나아지는 항목만 올립니다.
- 보고서 첫머리에 대상(파일, 커밋), 기준, 요약 표, 그리고 "차단 N건, 수정 N건, 권고 N건입니다." 줄을 씁니다.
- 마지막 메시지에는 요약 줄과 차단·수정 항목만 씁니다.
